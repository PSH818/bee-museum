# 东方蜜蜂蜂王 · 独立 Blender 模型

制作日期：2026-09-08。物种：东方蜜蜂 `Apis cerana`；职型：蜂王，雌性成蜂。

这是独立保存的静态科普展示模型，没有替换网站资源，也没有覆盖已有工蜂或旧蜂王模型。使用项目内工蜂的 Blender 建模工具函数作为基础，重新设计蜂王身体与附肢；本目录脚本可以独立运行，不依赖工蜂目录。

## 文件

- `apis-cerana-queen.blend`：Blender 5.1.2 可编辑母版，包含分件模型、材质节点、灯光、地面和三个相机。
- `apis-cerana-queen.glb`：仅模型的 GLB，不包含摄影棚、相机和灯光。
- `preview-hero.png`：斜前方展示图。
- `preview-dorsal.png`：俯视图。
- `preview-lateral.png`：侧视图。
- `build_model.py`：完整、可复现的 Blender 建模与导出脚本。
- `model-info.json`：实际导出尺寸与面数统计。
- `validate_model.py` / `validation.json`：结构检查和独立重新导入验证。

## 蜂王版本的处理

采用成年产卵蜂王的长腹部轮廓表达，不是把工蜂整体等比放大。

- 腹部重新构造为延长的椭圆轮廓，保留六块可见背板以及独立腹板；尾部明显超出翅尖。
- 体色采用深栗褐色、低对比棕色环带；腹部短毛稀疏，胸部保留较细的毛被。
- 后足为普通有毛胫节，没有工蜂的花粉筐、花粉团或采粉毛刷造型。
- 头部比例、复眼、胸部和足部姿态单独调整。每侧触角包含柄节、梗节和十节鞭节，每足有五节跗节及双爪。
- 四片翅轻度展开以便观察，口器折于头下，螫针收起。没有人为标记色点。

没有使用外部模型、照片贴图或 AI 图片。毛发为实际几何纤维，不依赖粒子系统；所有部件均有名称，方便在 Blender 内选择和修改。

## 尺度与使用

本模型的身体设计长度为约 14.4 mm（不含触角和足），这是展示模型的设定值，不是对某一采集标本的实测结果。整体包围盒以 `model-info.json` 为准。

Blender 中 `1 单位 = 1 毫米`，场景单位缩放 `0.001`；`+X` 朝尾部，`+Z` 朝背部。导出 GLB 时显式转换为米并采用 glTF 的 Y-up 约定。

在 Blender 中打开 `.blend` 后按 F12 可以渲染。相机为 `Camera_Hero`、`Camera_Dorsal`、`Camera_Lateral`；模型集合为 `01 | APIS CERANA • Queen`，摄影棚为 `02 | Studio & Cameras (not exported)`，模型根对象为 `Apis_cerana_queen`。

重新生成（会覆盖本目录同名输出）：

```powershell
& 'D:\blender\blender.exe' --background --python 'D:\artist\bee\beemodel\apis-cerana-queen-standalone\build_model.py'
```

## 精度与使用边界

这是分件可编辑的静态模型，尚未进行骨骼绑定、飞行动画或网页低模优化，不是扫描件，也不是物种鉴定模型。蜂王会因地域、年龄及生理状态呈现外形差异；本模型不指定亚种或地方品系。翅脉、口器微结构与表面细节经过展示性简化。

GLB 保留毛发几何、透明翅膜和标准 PBR 参数。Blender 中的程序化微凹凸、复眼微纹理和薄膜细节未烘焙为贴图，因此网页效果不会与 Cycles 预览完全相同。

## 参考资料

- [Masyithoh 等，2023：东方蜜蜂爪哇型幼龄蜂王形态测量](https://doi.org/10.13057/biodiv/d241044)。用于了解蜂王部件与形态变化范围；该研究对象是幼龄蜂王，其测量值不直接作为本模型成年产卵蜂王的统一比例。
- [De Souza 等，2015：蜂王、工蜂和中间型的形态识别](https://pmc.ncbi.nlm.nih.gov/articles/PMC4404332/)。用于蜂王与工蜂的职型结构比较，特别是后足花粉筐的有无；研究物种是西方蜜蜂，不将其中测量值当作东方蜜蜂数据。
- [佛罗里达大学：蜜蜂职型的外部形态对照](https://ask.ifas.ufl.edu/publication/IN1005)。辅助参考蜂王的延长腹部与整体外形；该资料同样以西方蜜蜂为对象。
