# 蜂之境 · 标本工作台交互方案(v3)

> 状态:方案定稿待实施,未改代码。2026-08-25。
> 参考:https://anatomyatelier.vercel.app/en 的三栏工作台、彩色标注点、底部扩展卡、居中弹卡式引导。
> 已定决策:首屏即工作台;顶部页签导航;来源保留独立页;"单独显示"与"图层"进首版;底部扩展卡在手机上收成"更多";**绒毛网格按区拆分(fuzz_head / fuzz_thorax / fuzz_abdomen),隔离时保留目标部位的毛**。

---

## 1. 目标

1. **零步进馆**:打开站点第一帧就是三维标本台,蜜蜂在转,一碰就能动。
2. **一屏看全**:左看馆藏、中看标本、右看档案、底看延伸,不用为了"找入口"离开标本。
3. **能拆能看**:标注点、单独显示、图层三件工具把"像拿放大镜看标本"做实。
4. **有人带**:一键讲解,五站走完一只蜂,收尾引向下一个展厅。
5. **URL 即真相**:蜂种、职型、部位、器官、隔离、图层、讲解站、时间轴全在 URL 里,可分享、可刷新恢复。
6. **手机可用**:纵向堆叠,工具收成一排图标,扩展卡折叠成"更多"。

## 2. 信息架构与路由

顶栏页签(全站唯一一级导航):**标本 · 生命历程 · 花朵四季 · 蜂蜜工坊 · 来源**(+ 右侧"关于"小链接)。

| 路由 | 页面 | 备注 |
|---|---|---|
| `/` | 标本工作台 · 西方蜜蜂 · 工蜂 | 即序厅;`/museum/world-bees` 301 到 `/` |
| `/museum/bees/:speciesId` | 标本工作台 · 指定蜂种 | 查询参数见 §7 |

| `/museum/flowers` `/museum/honey-workshop` | 工作台布局的占位:中栏空舞台 + 一句说明 + 底部卡引回标本 | 不再白页 |

单画布常驻:`/`、`/museum/*` 共用一个 Canvas 布局路由;换蜂种、进讲解、跳比较不重建画布;切"生命历程"页签在同一画布内做场景过渡(§8)。

断点:
- ≥ 1280:三栏如上。
- 1024–1279:左栏收成 72 px 图标栏(蜂种缩略图 + 悬停名),右栏 320。

## 4. 部件规格

### 4.1 顶栏
- 品牌 + 五个页签;当前页签用琥珀底色。
- 右侧:关于(文字链)、环境声开关、(手机)馆藏按钮。
- 高 64 px,浅色半透 + 模糊,和现有 `.topbar` 同一语言。

### 4.2 左栏 · 馆藏
- 页签 **蜂种 / 展厅**。
- 蜂种页签:6 行,每行 56 px 缩略图(从现有基线截图裁切)+ 中文名 + 科名;蜜蜂属两种行下展开 **工蜂 · 蜂王 · 雄蜂** 三个小 chip;独居蜂只显示"雌蜂"chip。当前项左侧一条 3 px 部位色(琥珀)竖线。
- 点蜂种 / chip:原地换标本(不换页),URL 变 `/museum/bees/:id?caste=`;换标本时舞台 250 ms 变暗、标注点先隐后现。
- 展厅页签:生命历程 / 花朵四季 / 蜂蜜工坊 / 来源,各带一行简介与状态(筹备中)。
- 底部"查看全部蜂种 →"(首版就是 6 种,链接到来源页的蜂种表)。

### 4.3 中栏 · 舞台与工具竖栏

工具竖栏 6 项,竖排在舞台左内侧,48 px 图标 + 9 px 标签,悬停高亮、激活态琥珀底:

| 工具 | 行为 | 状态 |
|---|---|---|
| **视角** | 点开 4 个机位:正 / 侧 / 背 / 微距(现有 vr 机位);再点回默认 | 显示当前机位名 |
| **放大** | 推近到当前聚焦部位(无聚焦则推近全身 1.4×);再点还原 | toggle |
| **单独显示** | 见下文 | toggle;无聚焦时禁用并提示"先点一个部位或圆点" |
| **图层** | 弹出 3 个开关:绒毛 / 翅 / 花粉团 | 面板;有关闭项时角标 |
| **比较** | 进入比较台(三职型;独居蜂/熊蜂改为"体型差异"对照) | 跳转 |
| **重置** | 视角回默认、退出单独显示、图层全开、关闭器官模式 | 一次性 |

**单独显示(isolate)**
- 前提:当前有聚焦部位(头/翅/腹/足)或已选器官。
- 开启:非目标部件切换为**幽灵材质**(同色系、透明度 0.12、不投影、`depthWrite=false`);目标部件正常;绒毛按区处理——目标部位的毛(fuzz_head / fuzz_thorax / fuzz_abdomen 之一)保留,其余隐去(依赖精模重导出,见 §12 第 2 步);其他部位的标注点隐藏,目标部位的标注点保留并放大 1.2×;镜头推近框住目标部位。
- 关闭 / 切部位 / 切蜂种:恢复原材质与镜头。切部位时不退出隔离,直接换目标(镜头平滑过去)。
- URL:`?isolate=1`(配合 `focus=` 或 `organ=`)。
- 讲解态会临时接管隔离,退出讲解后恢复用户此前的设置。

**图层(layers)**
- 绒毛 = `fuzz` 网格;翅 = `foreWingL/R + hindWingL/R`;花粉团 = `pollen_L/R`。
- 花粉团只在携粉的职型可用(目前仅西方蜜蜂工蜂精模带花粉),其余显示为禁用 + 提示"这只蜂不携带花粉团"。
- 开关状态跨蜂种保持(用户关了绒毛,换到熊蜂仍关);URL 只记关闭项:`?hide=fur,pollen`。
- 关绒毛时甲壳完整显示(需在实施第一步做一次视觉核对:六种精模在 fuzz 隐藏后底面是否完整、无破洞)。
- 关翅时翅根标注点隐藏;关花粉时花粉筐器官仍可选(器官卡说明"花粉团已隐藏")。
- 图层面板每项只给名称与开关,不加解说文字(避免新增待审文案)。

其他:右上 Tip 便签(现有)首访显示,拖动一次后淡出,悬停舞台左下"?"可再显;右下"自动旋转"开关(默认开,拖动后自动关,15 s 无操作不自动再开——避免和用户抢镜头)。

### 4.4 标注点
- 形态:实心圆 12 px + 白描边 2 px + 柔阴影;颜色 = 部位色:头 `#4a7bd0` / 翅 `#8a5fc9` / 腹 `#d0642f` / 足 `#3f8d5e` / 整体 `#c9861f`。左栏 chip、右栏关键数据图标、部位列表、底部卡角标都用这五色。
- 状态:默认 / 悬停(1.3×,浮签显示器官名)/ 激活(1.35× + 外圈光晕)/ 被遮挡(透明度 0.14、不可点)/ 隔离外(隐藏)。手机热区 34 px、视觉 16 px(现有规则)。
- 点击:先在点旁弹**小浮卡**(器官名 + 拉丁名 + 一句摘要 + [详情] [定位]);[详情] 把右栏切成器官模式并推近镜头;[定位] 只推近。再点同一点 = 详情。点空白处关浮卡。
- 键盘:Tab 可聚焦标注点(按部位顺序),Enter = 详情,Esc 关浮卡。

### 4.5 右栏 · 档案卡
整体模式(默认):
1. 眉题 `THE SPECIMEN · 西方蜜蜂` / 标题 **工蜂** / 拉丁名 + 英文名 / 一句副标(现 hero 文案)。
2. 描述(现 whole 观察条目的 description)。
3. **关键数据**(全部来自已审的 `beeSpecies` 字段):体长 · 科 · 分布 · 社会结构 · 筑巢 · 职型(数量);行前小图标用部位色。
4. Callout **科学边界**(模型说明;无则隐藏)、**你知道吗**(whole 条目的 fact)。
5. 主按钮 **开始讲解 →**;次按钮 **生命历程**(有对应故事时)/ **比较**;(测验:后期,不放占位)。
6. 来源徽章 + 来源列表(现有 Provenance);点徽章弹轻量浮层显示该条目来源与审查说明。

器官模式(点标注点"详情"后):顶部"← 回到整体",内容 = 现有器官卡(名称、拉丁名、摘要、功能、模型说明、来源);底部"下一个器官 →"按部位顺序遍历。

部位模式(左侧部位列表 / 讲解切换到头/翅/腹/足时):内容 = 现有 focus 观察条目(标题、描述、观察笔记、来源)。

右栏在桌面固定高度内滚动,不撑长页面。

### 4.6 底部扩展卡
桌面:一行 6 张 220 × 200 px,插图 + 眉题 + 标题 + 一个动词按钮;随当前蜂种变化:

| 卡 | 内容源 | 按钮 | 变化规则 |
|---|---|---|---|
| 微距 | 现有 macro 机位截图 | 看微距 → 工具竖栏"视角/微距" | 全部蜂种 |
| 三职型比较 / 体型差异 | 比较台 / 熊蜂"体型差异"事实卡 | 打开比较台 / 看差异 | 蜜蜂属 → 比较;其他 → 体型差异(独居蜂显示"雌蜂与雄蜂"待补时隐藏) |
| 生命历程 | 对应故事的时间轴缩略 | 播放一生 | 有故事的蜂种(西方蜜蜂、角额壁蜂);其他显示最近的故事并注明 |
| 花朵与四季 | 筹备 | — | 卡上标"筹备中",可点进占位页 |
| 来源与审校 | 状态徽章 + 该蜂种条目数 | 查看依据 → `/sources#species` | 全部 |
| 蜂蜜工坊 | 筹备 | — | 同上 |

手机(< 768):默认只显示 **2 张**(生命历程、比较/体型差异),其后一个 **"更多 (4)"** 折叠按钮;点开后其余 4 张纵向展开,再点"收起";展开状态记在会话内。

### 4.7 引导讲解(tour)
入口:右栏"开始讲解";URL `?tour=1`(站号)。

流程:
1. **弹卡**(居中,遮罩模糊):眉题"导览"、标题"认识一只工蜂"、一句说明、"5 站 · 约 2 分钟"、[开始] [稍后]。手机弹卡贴底。
2. **讲解态**:左右栏收窄 60% 并变暗;舞台放大;顶部页签禁用(仍可点 Esc 退出);底部中央出现**讲解条**(第 n/5 站 · 站名 · 2–3 句 · [上一站] [下一站] [退出],进度点 5 个)。
3. 每站 = 现有 whole / head / wing / abdomen / leg 观察条目(标题 + 描述;观察笔记作为"多看一眼"折叠)。镜头飞至该部位默认机位(现有 focus 机位),该部位标注点脉冲、其他部位标注点淡到 0.3;隔离状态临时开启为"目标部位"(可在讲解条上关掉"只看这一部位")。
4. 用户在讲解态仍可拖动模型;拖动后镜头不再自动纠正,直到"下一站"。
5. **收尾卡**:"看完了一只工蜂。接着看:三职型比较 / 一只工蜂的一生 / 换一种蜂",三个按钮;[退出]。
6. 退出:恢复讲解前的隔离、图层、镜头;URL 去掉 `tour`。
7. 键盘:← → 切站,Esc 退出;`prefers-reduced-motion` 时镜头瞬切、无脉冲。
8. 自动播放:讲解条上一个"自动"开关(默认关),开则每站 12 s 自动下一站。

每个蜂种/职型都有 5 条观察条目,所以 8 件标本天然都有讲解,不需要新写文案。

## 5. 生命历程页签
现有页面套进同一顶栏与画布布局:左栏改为"故事 / 阶段"两页签(故事 = 两条时间轴,阶段 = 现有阶段列表),中栏为场景 + 时间轴,右栏为阶段卡 + 分支。"相关展品"链接在同一画布内切回标本工作台并带上 `focus=`/`organ=`。

## 6. 手机版(< 768)
自上而下:
1. 顶栏 52 px:品牌、页签折叠为"≡"、馆藏按钮。
2. 舞台 56 vh:顶部横向**蜂种/职型 chip 条**(现有);工具竖栏变为舞台底边一排 6 个图标(标签隐藏,长按出名);Tip 便签隐藏;自动旋转开关右下。
3. 档案卡(全宽,非浮层):模式切换同桌面;"开始讲解"按钮全宽。
4. 底部扩展卡:2 张 + "更多 (4)"。
5. 讲解条贴底(安全区内),左右滑切站;弹卡贴底。
标注点点击直接进入器官模式(不弹浮卡,浮卡在小屏上遮挡),右栏卡随之滚动到视口。

## 7. URL 参数
| 参数 | 值 | 说明 |
|---|---|---|
| `caste` | worker/queen/drone | 缺省 worker |
| `focus` | whole/head/wing/abdomen/leg | 部位模式 |
| `organ` | 器官 id | 器官模式(优先于 focus) |
| `compare` | 1 | 比较台 |
| `isolate` | 1 | 单独显示 |
| `hide` | fur,wings,pollen 的子集 | 关闭的图层 |
| `view` | front/side/back/macro | 工具竖栏机位 |
| `tour` | 1–5 | 讲解站号 |
| `t` | 数字 | 生命历程时间轴 |
| `vr` / `motion` | 测试专用 | 不变 |

全局 store(Zustand):当前标本缓存(最近 3 件)、过渡状态、画质档、环境声、首访提示已看、手机"更多"展开、自动旋转。URL 之外的都不持久化到服务端;`localStorage` 只存首访提示与环境声。

## 8. 过渡与动效
| 场景 | 时长 | 说明 |
|---|---|---|
| 换蜂种 | 250 ms 暗出 → 就绪 → 300 ms 亮入 | 标注点随之隐/现;镜头保持 |
| 切部位 / 器官定位 | 1.2 s 镜头飞行(现有 rig,拖动即释放) | |
| 单独显示开关 | 350 ms 透明度渐变 + 镜头飞行 | |
| 图层开关 | 200 ms 渐隐/渐现 | |
| 进讲解 | 弹卡 200 ms;讲解态布局 400 ms | |
| 切页签到生命历程 | 250 ms 暗出 → 场景就绪 → 镜头从当前位飞入 → 300 ms 亮入 | 同一画布 |
| 首屏 | 海报 → 实时画面 300 ms 交叉淡出 | 低精 GLB 先到 |
`prefers-reduced-motion`:全部改为 ≤ 100 ms 或瞬切。

## 9. 无障碍与可用性
- 所有工具、标注点、chip、卡按钮均可键盘操作并有 `aria-pressed/expanded`;标注点有可读名称。
- 讲解条 `role=dialog` + `aria-live` 报站。
- 颜色不是唯一编码:标注点浮签有文字;图层开关有文字标签。
- 触控热区 ≥ 34 px;工具图标 48 px。
- 舞台 `touch-action: none`(现有),页面其余部分正常滚动。

## 10. 风险与对策
| 风险 | 对策 |
|---|---|
| 绒毛原为一整张网格 | **已决定拆分**:Blender 导出按 `_fur_zone` 拆成 `fuzz_head / fuzz_thorax / fuzz_abdomen`(约半天,含 6 种精模重导出与全部视觉基线重生成);hero 加载器的 FOCUS_BY_NAME 增加 `fuzz_*` → 对应部位的映射;生命历程场景按 `/^fuzz/` 前缀匹配不受影响 |
| 关闭绒毛后底面可能有未烘到的区域 | 实施第 1 天做六种精模的"无毛"视觉核对,必要时补烘 |
| 幽灵材质在低端手机上的透明排序/性能 | 幽灵材质不投影、不写深度;手机上隔离时同时把 dpr 降 1 档 |
| 讲解镜头与用户拖动冲突 | 沿用"拖动即释放镜头"规则;下一站重新接管 |
